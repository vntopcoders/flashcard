# Kế hoạch học IELTS chi tiết từng ngày - Từ 4.0 lên 7.0

## 📋 TỔNG QUAN
**Thời gian:** 6 tháng (180 ngày)
**Thời gian học/ngày:** 2.5-3 tiếng
**Mục tiêu từng giai đoạn:**
- Tháng 1-2: 4.0 → 5.5
- Tháng 3-4: 5.5 → 6.5  
- Tháng 5-6: 6.5 → 7.0+

## 📈 MILESTONE TRACKING

### **Tuần 2:** First checkpoint
- [ ] 300 từ vựng mới
- [ ] Grammar Units 1-15 hoàn thành
- [ ] Làm được 1 Cambridge test trong thời gian
- [ ] Speaking Part 1 tự tin

### **Tuần 4:** Month 1 milestone  
- [ ] 600 từ vựng
- [ ] Basic grammar solid (Units 1-30)
- [ ] Reading 180+ words/minute
- [ ] Writing Task 1 cấu trúc đúng
- **Target score:** 5.0-5.5

### **Tuần 8:** Month 2 milestone
- [ ] 1200 từ vựng
- [ ] Grammar Units 1-60
- [ ] Reading 200+ words/minute  
- [ ] Writing coherent paragraphs
- **Target score:** 5.5-6.0

### **Tuần 12:** Month 3 milestone
- [ ] 2000 từ vựng
- [ ] Advanced grammar structures
- [ ] All question types mastery
- [ ] Speaking fluency 3+ minutes
- **Target score:** 6.0-6.5

### **Tuần 16:** Month 4 milestone
- [ ] 2800 từ vựng
- [ ] Complex sentence structures
- [ ] Reading 220+ words/minute
- [ ] Writing Task 2 under 40 minutes
- **Target score:** 6.5+

### **Tuần 20:** Month 5 milestone  
- [ ] 3500 từ vựng
- [ ] Band 7 writing techniques
- [ ] Reading 250+ words/minute
- [ ] Speaking sophistication
- **Target score:** 7.0-

### **Tuần 24:** Final milestone
- [ ] 4000+ từ vựng active use
- [ ] Consistent band 7+ mock scores
- [ ] Exam confidence 100%
- **Target score:** 7.0+
